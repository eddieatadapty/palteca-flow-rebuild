# Palteca Growth Audit

**Live → https://eddieatadapty.github.io/palteca-flow-rebuild/**

Five ideas to turn more Palteca users into subscribers, each built into a clickable version of Palteca's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask two questions, then use both answers | +10–20% CR to purchase |
| 02 | Let them understand a native speaker before the paywall | +5–15% CR to purchase |
| 03 | Make the yearly saving impossible to miss | +10–15% ARPU, from more yearly plans |
| 04 | Show the price first, ask for the account after | +5–10% CR to purchase, ARPU +10–17% |
| 05 | Catch the people who close the paywall | +10–15% ARPU |

Every price, rating and feature comes from Palteca's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Palteca. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
